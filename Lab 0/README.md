# Lab 0 — Odometry and Environment Mapping

C++ implementation of robot odometry, environment mapping, and trajectory visualization.

## Files

| File | Description |
|------|-------------|
| `1_odometry.cpp` | Basic odometry calculation from wheel encoders |
| `2_odometry_taskA2.cpp` | Enhanced odometry with task A2 |
| `3_environment_map.cpp` | Builds an environment map from sensor data |
| `4_trajectory_map.cpp` | Plots robot trajectory on the map |
| `plot_task1.py` — `plot_task4.py` | Python scripts to visualize results |
| `animation.py` | Generates robot animation GIF |
| `robot_animation.gif` | Animated robot trajectory |

## Outputs

- `EnvironmentMap_plot.png` — Reconstructed environment map
- `Trajectories-Map_plot.png` — Robot trajectory on the map
- `trajectory1_plot.png` — Individual trajectory plot
- `trajectory_both_plot.png` — Combined trajectories
